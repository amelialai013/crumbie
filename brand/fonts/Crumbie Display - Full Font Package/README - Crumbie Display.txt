WHAT MATCHES THE EXAMPLES
The supplied vector outlines for A B C D E G I L M N O R S T U Y were extracted directly from Figma, rather than traced from a screenshot. Their shapes are retained using uniform scaling and standard font metrics. OTF preserves cubic curves; TTF uses a high-precision quadratic conversion.
The examples contain slight differences between repeated letters. These are preserved as optional OpenType stylistic sets:
  Default: Club Crumbie logo lettering, supplemented by the other samples.
  ss01: Coming Soon alternates for C, M and N.
  ss02: Stay Tuned alternates for T, U, N and E.
Font spacing and baseline metrics are normalised for typesetting; the original two-line logo layout is not a font glyph or automatic lockup.

MATCHING ADDITIONS
The samples do not contain F H J K P Q V W X Z, numbers or punctuation. Those characters were drawn to match and are not claimed as exact copies of unseen source artwork. The solid display zero reuses the supplied O outline. glyph-provenance.csv distinguishes supplied shapes from new designs.

CHARACTER SET
A–Z, a–z mapped to the same uppercase shapes, 0–9, all 95 printable ASCII characters, curly quotes, en/em dashes, ellipsis, bullet and nonbreaking space. This is an all-caps display font: it does not contain separate lowercase forms, accented alphabets or general multilingual coverage.

INSTALLATION
Install either the OTF or the TTF; installing both may create duplicate family entries. The family name is Crumbie Display and the style is Regular. Standard desktop font installation is required; the font was not automatically installed on your computer or added to the live website.
For websites, use the WOFF2 with font-family 'Crumbie Display'; the preview HTML contains an example @font-face. ss01/ss02 require an application with OpenType stylistic-set support.

This is a new custom font built from the supplied lettering, not a replacement copy of AM Futurismo or DM Sans. Source-artwork rights remain unchanged; no additional rights in that artwork are granted by this package.
